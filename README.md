## How to redeem a Muse invite code

1. Join Muse at https://muse.ai/join
2. Redeem the code **within 48 hours of joining**. After 48 hours, the redemption entry may no longer be available.
   - Mobile app: **Settings > Redeem token**
   - Web (muse.ai): **Settings > General > Usage > Redeem invite code**
3. Enter **F8R3CV** or **NVA0AS** and confirm.
4. If one code is reported as used up or invalid, try the other code once. Do not keep retrying codes repeatedly.

## What do you get?

According to the Muse invitation screen (checked on 2026-11-12), a successful redemption gives **1 billion Muse tokens to the inviter and 1 billion Muse tokens to the invitee**. Opening the join link alone is not a redemption — the code must be entered and confirmed in Settings.

Current offer terms, remaining spots, and the final redemption result are shown on Muse's own invitation and redemption screens.

## FAQ

**Can I use both codes?**
No. Each account can confirm one redemption only. Pick F8R3CV or NVA0AS.

**Does the inviter see my chats if I use their code?**
No. An invitation does not give the inviter access to the invitee's chats or personal AI agent.

**I joined Muse more than 48 hours ago. Can I still redeem?**
On mobile, Redeem token is only available during the first 48 hours after joining, so an older account will most likely not be able to redeem.

**Are these codes guaranteed to stay available?**
No. Invite codes have limited spots. This README is the status page for these two codes and will be updated when they run out.
